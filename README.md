# SIP Retention Discovery Engine

A product case study for Groww: what helps first-time mutual-fund investors keep an SIP running 12 months after they start.
The app shows the output of a discovery engine that analysed 2,339 public comments from the Play Store, Reddit, TradingQnA, YouTube and other sources.

All numbers are pre-computed. The app runs no analysis and calls no AI at runtime.
Author names and handles were removed from the data files. Each comment links back to its original public post.

This repository is generated from the main project by `deploy/build_app_repo.py`. Don't edit it by hand.
